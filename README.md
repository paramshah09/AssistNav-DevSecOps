# AssistNav - Assistive Navigation System (Prototype)

Simulated demonstration data only. No internet, GPS, API keys or installation needed.

1. Open `index.html` in Chrome, Edge or Firefox.
2. Select start location.
3. Select destination.
4. Select accessibility preference.
5. Click **Find Accessible Route**.
6. Select a route.
7. Demonstrate navigation (Next step) and **Emergency / Help**.
